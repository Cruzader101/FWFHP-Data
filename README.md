# FWFHP PHQ-2 Analysis

Analysis of PHQ-2 depression screening among patients seen at the Farm Worker Family
Health Program (FWFHP) night camps, 2024–2026. The scripts:

- compare the FWFHP PHQ-2 positive rate (score > 2) to a survey-weighted NHANES
  reference of Hispanic adults,
- model which patient characteristics (camp, age, sex, drug screen) predict a
  positive screen,
- test whether 12 physical diagnoses co-occur with higher PHQ-2 scores, with
  sensitivity diagnostics, and
- measure how often a positive screen led to a depression/anxiety diagnosis.

> **The patient data is not in this repository and must never be committed.**
> Anyone reproducing the results downloads their own copy from REDCap (see below).
> `.gitignore` excludes `Night Camp Data/`, `Night Camp/`, `archive/`, `logs/`, and
> any file named `FarmWorkerFamilyHeal*`. Check `git status` before every commit.

## Quick start

```bash
pip install -r requirements.txt     # Python 3.13; see "Environment" below
# put the REDCap export in "Night Camp Data/" (see "Getting the data from REDCap")
python run_all.py
```

`run_all.py` runs every script in order, writes the charts to `charts/`, and saves
each script's console output (every count, OR, CI and p-value) to `logs/`.

## Repository layout

| Path | What it is |
|---|---|
| `run_all.py` | Runs the whole pipeline in dependency order |
| `data_paths.py` | Where the scripts look for the REDCap export |
| `dataframes.py` | Builds the NHANES Hispanic reference file from the raw NHANES files |
| `analyses.py` | FWFHP vs. NHANES comparison; logistic regression for predictors of PHQ-2 > 2 |
| `co_occurences.py` | Physical diagnoses vs. PHQ-2 > 2 (Fisher's exact, Benjamini–Hochberg FDR) |
| `co_occurrences_continuous.py` | Physical diagnoses vs. PHQ-2 score as a continuous predictor (logistic, FDR) |
| `co_occurrence_sensitivity.py` | Leave-one-out, fragility index, camp clustering, linearity, and PHQ-2 scoring checks |
| `care_gap.py` | Screening status × depression/anxiety diagnosis |
| `DPQ_L.xpt`, `DEMO_L.xpt` | Raw NHANES files (public data) |
| `NHANES/df_Hispanic_NHANES.csv` | NHANES reference file generated by `dataframes.py` |
| `charts/` | Generated figures |

## Environment

The results were produced with Python 3.13.5 and the exact package versions pinned in
`requirements.txt`. To set up an isolated environment:

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
source .venv/bin/activate       # macOS / Linux
pip install -r requirements.txt
```

## Getting the data from REDCap

All FWFHP scripts read **one** REDCap export.

1. In the FWFHP REDCap project, open **Data Exports, Reports, and Stats** and choose the
   saved report used for this analysis. REDCap builds the file name from the first 20
   letters/digits of the project and report titles. The report is the one whose export
   is named `FarmWorkerFamilyHeal-2426FWFHPDataAnalysi_DATA_LABELS_<timestamp>.csv`.
   If you have to rebuild the report, include every field in the table below.
2. Export as **CSV / Microsoft Excel (labels)**, not raw data. The scripts look up
   columns by their label text and compare values to label text such as `"Yes"`.
   A raw export has field names and numeric codes and won't work.
3. Save the file into a folder named `Night Camp Data/` at the root of this repo, without
   renaming it.

### Pinned export

The current results come from
`Night Camp Data/FarmWorkerFamilyHeal-2426FWFHPDataAnalysi_DATA_LABELS_2026-07-06_1745.csv`
(set in `data_paths.py`). To reproduce the published numbers, use that exact file.
A newer export will contain more records and give different numbers. To run against
a newer export:

```bash
python run_all.py --data "Night Camp Data/<new export>.csv"
```

Or set the `FWFHP_EXPORT` environment variable, which also applies when running the
scripts one at a time.

As a sanity check, the pinned export has 2,074 rows, and the analytic cohort (adults 18+
with a PHQ-2 score) is 1,889.

### Columns used

Column headers must match **exactly**, including the quirks noted below, because the
scripts select columns by header text.

**Demographics and screening**

| Export column (label) | Used by | Notes |
|---|---|---|
| `Record ID` | all | |
| `PHQ-2 Score` | all | Total 0–6. Rows with a blank score are excluded |
| `Age` | all | Cohort is restricted to `Age >= 18` |
| `Camp` | `analyses.py`, `co_occurrence_sensitivity.py` | |
| `Sex` | `analyses.py` | |
| `Drug Use Screen Result` | `analyses.py` | `"Yes"` = positive screen; anything else = no documented positive screen |
| `Little interest or pleasure in doing things. ` | `co_occurrence_sensitivity.py` | PHQ-2 item 1. **Header ends with a trailing space** |
| `Feeling down, depressed, or hopeless` | `co_occurrence_sensitivity.py` | PHQ-2 item 2 |

The two PHQ-2 item columns are only used to check the stored `PHQ-2 Score`. Their
values must start with `Not at all`, `Several days`, `More than half`, or
`Nearly every day`.

## NHANES reference data

`DPQ_L.xpt` (depression screener) and `DEMO_L.xpt` (demographics) are from the NHANES
August 2021–August 2023 cycle. They're public and included in the repo. To re-download:

- https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2021/DataFiles/DPQ_L.xpt
- https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2021/DataFiles/DEMO_L.xpt

Variables used: `SEQN` (join key), `DPQ010` + `DPQ020` (PHQ-2 items; 7/9 =
refused/don't know, treated as missing), `RIDRETH3` (1 = Mexican American,
2 = Other Hispanic), `RIDAGEYR` (age, restricted to 18+), and `WTMEC2YR`, `SDMVSTRA`,
`SDMVPSU` (survey weight and design variables).

## Running scripts one at a time

Each script is split into `# %%` cells and can be run interactively in VS Code or
Jupyter from the repo root. Run `dataframes.py` before `analyses.py`, because
`analyses.py` reads the NHANES file it writes. The other scripts can run in any order.
